# Bloc marque : exemples officiels

Extraits de code des pages d'exemple du DSFR 1.15.4. Les `id` sont à rendre uniques dans la page qui les reprend. Les extraits de plus de 4 ko sont dans des fichiers à part.

### Logo MD (par défaut)

```html
<p class="fr-logo">
    Intitulé
    <br>officiel
</p>
```

### Logo SM

```html
<p class="fr-logo fr-logo--sm">
    Intitulé
    <br>officiel
</p>
```

### Logo LG

```html
<p class="fr-logo fr-logo--lg">
    Intitulé
    <br>officiel
</p>
```
