# Mise en exergue : exemples officiels

Extraits de code des pages d'exemple du DSFR 1.15.4. Les `id` sont à rendre uniques dans la page qui les reprend. Les extraits de plus de 4 ko sont dans des fichiers à part.

### Exergue taille sm

```html
<div class="fr-highlight">
    <p class="fr-text--sm">Lorem [...] elit ut.</p>
</div>
```

### Exergue taille md

```html
<div class="fr-highlight">
    <p>Lorem [...] elit ut.</p>
</div>
```

### Exergue taille lg

```html
<div class="fr-highlight">
    <p class="fr-text--lg">Lorem [...] elit ut.</p>
</div>
```

### Exergue accentué

```html
<div class="fr-highlight--green-emeraude fr-highlight">
    <p>Lorem [...] elit ut.</p>
</div>
```
